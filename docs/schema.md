## Tables

### `users`
Covers both guests and operators. Role field determines which app they access.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key, default `gen_random_uuid()` |
| `name` | `text` | Full name |
| `email` | `text` | Unique |
| `phone` | `text` | WhatsApp-formatted, e.g. `+18765551234` |
| `role` | `text` | `guest` or `operator` |
| `created_at` | `timestamptz` | Default `now()` |

---

### `operators`
One row per operator business (Bob's Taxis, Sandals Royal, etc.)

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key |
| `user_id` | `uuid` | FK → `users.id` |
| `name` | `text` | Business name, e.g. `Bob's Taxis` |
| `type` | `text` | `transfer`, `hotel`, `tour`, `restaurant` |
| `whatsapp_number` | `text` | Used by Agent 3 to send notifications |
| `is_available` | `bool` | Default `true` — operator online/offline toggle |
| `created_at` | `timestamptz` | Default `now()` |

---

### `trips`
One trip per guest booking window.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key |
| `guest_id` | `uuid` | FK → `users.id` |
| `status` | `text` | `active`, `disrupted`, `resolved` |
| `created_at` | `timestamptz` | Default `now()` |

---

### `bookings`
Each individual service booked within a trip.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key |
| `trip_id` | `uuid` | FK → `trips.id` |
| `operator_id` | `uuid` | FK → `operators.id` |
| `type` | `text` | `flight`, `transfer`, `hotel`, `tour`, `restaurant` |
| `status` | `text` | `confirmed`, `pending`, `rescheduled`, `cancelled` |
| `scheduled_time` | `timestamptz` | Original booking time |
| `updated_time` | `timestamptz` | Rescheduled time, null if unchanged |
| `notes` | `text` | Optional freetext (flight number, room type, etc.) |
| `created_at` | `timestamptz` | Default `now()` |

---

### `disruptions`
Fired by Agent 1 when a flight delay or cancellation is detected.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key |
| `trip_id` | `uuid` | FK → `trips.id` |
| `type` | `text` | `flight_delay`, `cancellation`, `weather` |
| `delay_minutes` | `int` | How long the delay is in minutes |
| `detected_at` | `timestamptz` | When Agent 1 wrote this row |
| `raw_data` | `jsonb` | Full API response from flight status provider |
| `resolved` | `bool` | Default `false` — Agent 5 sets to `true` when done |

---

### `operator_alerts`
Written by Agent 3. One row per operator per disruption.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key |
| `disruption_id` | `uuid` | FK → `disruptions.id` |
| `operator_id` | `uuid` | FK → `operators.id` |
| `booking_id` | `uuid` | FK → `bookings.id` |
| `message` | `text` | The notification message generated by Claude |
| `status` | `text` | `pending`, `confirmed`, `declined` |
| `created_at` | `timestamptz` | Default `now()` |
| `responded_at` | `timestamptz` | When operator confirmed or declined |

---

### `chat_messages`
The guest-facing chat feed. Written by Agent 5.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` | Primary key |
| `trip_id` | `uuid` | FK → `trips.id` |
| `sender` | `text` | `ai` or `guest` |
| `body` | `text` | Message content |
| `created_at` | `timestamptz` | Default `now()` — used for ordering |

---

## Realtime

Enable Realtime on these tables in Supabase dashboard (Database → Replication):

| Table | Why |
|---|---|
| `bookings` | Guest app updates booking status in real time |
| `operator_alerts` | Operator portal receives new alerts live |
| `chat_messages` | Guest chat feed streams new messages |
| `disruptions` | Guest app switches to disruption screen on insert |
